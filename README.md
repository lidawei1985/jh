# LDW-Cinema-Universal

通用版独立交付目录。手机版预览构建在独立源码副本中维护，不修改原 TVBOXTV 工作区或稳定版。

## 当前手机版

- 当前交付：`LDW-Cinema-Mobile-v60.apk`（桌面文件名：`1.0.60-手机版-最新.apk`）
- 内部版本：`versionCode 60` / `1.0.60-mobile`
- 独立包名：`com.ldw.cinema.mobile`，可与电视版同时安装。
- 软件更新只读取 `update-mobile.json`；片源、搜索规则和直播配置继续与电视版同步。
- 默认免启动密码，顶部 LDW TV LOGO 保留成人隐藏入口。
- 首页使用可左右翻页、自动切换的真实可播放“今日精选”，并提供多行分类推荐。
- 成人模式同步正常模式布局和继续观看逻辑，并使用成人电影、成人系列、新片速递、热门榜单及成人专属分类。
- 成人继续观看与普通模式完全隔离，切换模式不会互相显示播放记录。
- 继续观看海报支持播放进度条；长按可继续播放、从头播放或移出继续观看。
- 播放达到 95% 后自动完成：有下一集则推进记录，最终一集或电影则移出继续观看。
- 成人模式中的首页、返回和各页面导航保持成人模式，模式切换只通过顶部隐藏入口。
- 海报采用磁盘缓存/网络加载、特殊图床请求头、HTTP/1.1 原生下载和三次重试多级后备；单张图片失败不再删除影片卡片。
- 播放器支持单击播放/暂停、进度拖动、选集、线路、倍速、片头片尾、主页、返回和强制横竖屏。
- 播放退出时保存影片、集数和进度；首页继续观看可恢复对应内容。

## 安装

在 Android 手机安装当前 `LDW-Cinema-Mobile-v60.apk`。该包已在 OPPO A5x 5G（Android 16，720×1604 竖屏）覆盖安装和冷启动验证。

片源、海报和播放线路依赖网络，上游接口变化可能导致内容不可用。预览包不代表远程稳定版已更新。

## 兼容性记录

- 已有交接记录：MuMu 安装、启动无闪退；正常/成人模式、收藏/历史隔离、搜索去重、播放线路轮换和数据源回滚等改动保留。
- 手机版已改为竖屏：首页采用手机入口网格，推荐区和状态栏无竖屏裁切；密码页保留专用竖屏数字键盘。
- 手机预览版默认关闭启动密码并直接进入首页；可在设置中重新开启。成人隐藏入口逻辑未删除。
- 播放页应用导航移到顶部，底部完整保留播放器进度条和功能按钮，暂停时不再互相遮挡。
- 成人片源返回空分类时不再导致首页崩溃，分类异步回调也会校验当前模式。
- 自动化移动端布局与行为测试：57 项通过；Release 已核验 V1/V2/V3 签名。
